# 🌐 PROJECT‑1 – Simple Web Layout

PROJECT‑1 is a basic front‑end website created to practice fundamental HTML, CSS and JavaScript skills.  
The goal of this project was to build a clean, responsive layout and strengthen core web development techniques.

## ✨ Features
- Simple and clean page structure
- Fully responsive layout
- Custom styling without frameworks
- Lightweight and easy to maintain
- Practice project focused on fundamentals

## 🛠 Technologies
- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**

## 🎯 Purpose
This project was created as an early front‑end exercise to improve my understanding of layout building, styling, and basic interactivity. It represents the foundation of my journey into modern web development.
